## LAT 延迟

板级观察到屏幕右上角 LAT 约 **50～90 ms**。此范围来自使用者观察调试计数，尚未记录逐模式样本量、分位数及对应 bit / ELF 版本。

测量逻辑位于 [video_out.v](../FPGA/user_source/hdl_source/video_out.v) 的 `final1_latency`：

- **起点**：接收某源帧的 RAW SOF 事件。
- **终点**：同一源帧在 HDMI 发送端输入出现首个有效像素。
- **配对**：通过源帧号关联采集与显示事件。
- **计时**：事件跨域到 100 MHz 测量时钟域后打时间戳，以 1 μs 为单位计算时间差；两条事件同步路径带来少量计时偏差。

因此，LAT 表示帧缓存、处理和显示调度引入的内部延迟，测量边界不包含 RAW 帧首以前的曝光时间、TMDS 串行发送及外部显示器响应。重复显示旧帧会增加该帧的显示年龄，阅读 LAT 时应同时观察 IN/OUT/FD 计数和画面是否更新。

## 后续测量口径

记录性能时，统一保存源码提交、bit / ELF SHA-256、模式与 FX、曝光状态及测量时长。

| 项目 | 方法 |
| --- | --- |
| 实际采集帧率 | 在固定时间窗统计新的源帧号 |
| 完成处理帧率 | 同一时间窗统计完成发布的帧，重复帧单独计数 |
| LAT 分布 | 在稳定模式下采样有效 LAT，分别记录最小值、最大值、中位数与样本量 |
| 跟踪误差 | 明确目标中心与图像中心的距离定义，记录场景、目标运动和像素误差 |
| 场景到屏幕延迟 | 同时拍摄真实事件与屏幕响应，按录像帧率计算时间差 |
